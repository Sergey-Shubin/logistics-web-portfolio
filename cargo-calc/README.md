# CargoCalc

Учебный pet‑проект: калькулятор ориентировочной стоимости автомобильной перевозки.

## Возможности
- расчёт по расстоянию и ставке;
- коэффициент срочности;
- дополнительный коэффициент для тяжёлого груза;
- опциональное страхование;
- адаптивная верстка;
- валидация числовых полей.

## Технологии
HTML5, CSS3, JavaScript (ES6), Intl.NumberFormat.

## Запуск
Откройте `index.html` в браузере.
