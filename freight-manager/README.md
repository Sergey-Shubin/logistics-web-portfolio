# FreightManager

Учебное веб-приложение для управления заявками на грузоперевозки.

## Возможности
- добавление заявки;
- автоматический расчёт стоимости перевозки;
- учёт расстояния, веса, ставки и срочности;
- опциональное страхование;
- таблица перевозок;
- поиск по клиенту и маршруту;
- фильтрация по статусу;
- сортировка по стоимости и расстоянию;
- изменение статуса заявки;
- удаление заявки;
- сводная статистика;
- сохранение данных в localStorage;
- адаптивный интерфейс.

## Технологии
HTML5, CSS3, JavaScript (ES6), Web Storage API, Intl.NumberFormat.

## Запуск
Откройте `index.html` в браузере.
