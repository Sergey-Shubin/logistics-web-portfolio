# Как загрузить это портфолио на GitHub через браузер

1. Войдите на github.com.
2. Нажмите **New repository**.
3. Название: `logistics-web-portfolio`
4. Выберите **Public**.
5. Не добавляйте README, .gitignore и License — они уже есть в архиве.
6. Нажмите **Create repository**.
7. На странице пустого репозитория выберите **uploading an existing file**.
8. Распакуйте архив `logistics-web-portfolio.zip`.
9. Перетащите всё содержимое папки `logistics-web-portfolio` в окно GitHub.
10. В поле commit message напишите: `Initial portfolio`
11. Нажмите **Commit changes**.

## Включить GitHub Pages
1. Откройте **Settings** репозитория.
2. Слева выберите **Pages**.
3. В разделе Build and deployment выберите **Deploy from a branch**.
4. Branch: `main`, folder: `/ (root)`.
5. Нажмите **Save**.

После публикации появится ссылка вида:
`https://ВАШ-ЛОГИН.github.io/logistics-web-portfolio/`

Эту ссылку можно ставить в резюме как портфолио.
