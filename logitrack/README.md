# LogiTrack

Учебный pet‑проект: мини‑панель для учёта заявок на перевозку.

## Возможности
- таблица заявок;
- добавление новой заявки;
- поиск по клиенту и маршруту;
- фильтр по статусу;
- смена статуса;
- удаление заявки;
- расчёт статистики;
- сохранение данных в localStorage;
- адаптивный интерфейс.

## Технологии
HTML5, CSS3, JavaScript (ES6), Web Storage API.

## Запуск
Откройте `index.html` в браузере.
