# Logistics Web Portfolio

Стартовое портфолио начинающего веб-разработчика.

## Проекты

### 1. CargoCalc
Калькулятор ориентировочной стоимости грузоперевозки.

**Технологии:** HTML5, CSS3, JavaScript.

### 2. LogiTrack
Мини-панель для учёта заявок на перевозку.

**Возможности:** поиск, фильтры, статусы, статистика, localStorage.

**Технологии:** HTML5, CSS3, JavaScript, Web Storage API.

### 3. FreightManager
Веб-приложение для управления перевозками.

**Возможности:** создание заявок, автоматический расчёт стоимости, статусы, фильтрация, сортировка, статистика, localStorage.

**Технологии:** HTML5, CSS3, JavaScript, Web Storage API.

## Запуск локально
Откройте корневой `index.html` в браузере.

## GitHub Pages
Репозиторий подготовлен для публикации через GitHub Pages без сборки.
После загрузки файлов:
1. Settings → Pages
2. Source: Deploy from a branch
3. Branch: `main`
4. Folder: `/ (root)`
5. Save

Через некоторое время GitHub выдаст публичную ссылку на портфолио.
